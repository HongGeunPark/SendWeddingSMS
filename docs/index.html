청첩장 연락처 사용설명서

휴대폰 연락처에서 보낼 사람을 고르고, 사람마다 이름을 넣은 문자에 모바일 청첩장 주소를 붙여 한 번에 보내는 앱이에요. 설치부터 보내기까지 순서대로 적었어요. 아래 화면은 따라 보기 쉽게 그린 그림이라 실제 폰 화면과 글씨 모양이 조금 다를 수 있어요.

주황색 테두리가 그 화면에서 누를 곳이에요. 처음부터 끝까지 약 1분이에요.

처음 한 번만

앱 설치하기

  1. 아버지 폰에서 위의 앱 받기를 누르거나, 카톡으로 받은 주소를 눌러요. SendWeddingSMS.apk 파일이 내려받아져요.
  2. “파일이 기기를 손상시킬 수 있다”는 안내가 나오면 다운로드 또는 무시하고 다운로드를 눌러요. 직접 만든 앱이라 플레이스토어에 없어서 나오는 안내예요.
  3. 다 받아지면 화면 아래의 열기를 눌러요. 못 찾으면 내 파일 → 다운로드에서 파일을 눌러도 돼요.
  4. “출처를 알 수 없는 앱” 안내가 나오면 설정을 누르고 이 출처 허용을 켠 뒤 뒤로 가기를 눌러요.
  5. 설치를 눌러요. Play 프로텍트 경고가 나오면 세부정보 더보기 → 무시하고 설치를 눌러요.
  6. 홈 화면에 청첩장 연락처 앱이 생겨요.
새 버전이 나오면 같은 주소에서 다시 받아 그대로 설치하면 돼요. 이전에 넣어 둔 청첩장 주소와 보낸 기록은 그대로 남아요.
1단계 / 3

보낼 문구 쓰기

  1. 모바일 청첩장 주소 칸에 청첩장 링크를 붙여 넣어요. 한 번 넣으면 다음에도 남아 있어요.
  2. 처음이라면 예시 문구 불러오기를 눌러 어르신·친구·직원·거래처 중 하나를 고르세요. 불러온 다음 마음대로 고치면 돼요.
  3. 문구 중간에 받는 사람 이름을 넣고 싶은 자리에 커서를 두고 버튼을 눌러요.
    • + 이름을 누르면 {이름}이 들어가요. “{이름}님” → “김철수님”
    • + 이름아/야를 누르면 {이름아}가 들어가요. “철수야”, “길동아”처럼 부르는 말이 돼요.
  4. 아래 미리보기에서 실제로 어떻게 갈지 확인해요. 청첩장 주소는 문구 아래 한 줄 띄우고 자동으로 붙어요.
  5. 다음: 받는 사람 고르기를 눌러요.
어르신께 보낼 문구와 친구에게 보낼 문구가 다르면, 한 번에 한 문구씩 보내면 돼요. 어르신들 먼저 다 보내고 나면 처음 화면으로 돌아오니, 그때 친구용 문구를 새로 쓰면 돼요.
2단계 / 3

받는 사람 고르기

  1. 처음에는 연락처 권한 허용을 누르고 허용을 눌러요. 연락처는 폰 안에서만 쓰고 밖으로 보내지 않아요.
  2. 보낼 사람 옆 네모를 눌러 체크해요.
  3. 사람이 많으면 위 검색 칸을 써요. 이름, 초성(예: ㄱㅊㅅ), 전화번호 일부로 찾을 수 있어요.
  4. 위의 전체 / 고른 사람 / 안 보낸 사람을 누르면 목록이 걸러져요. 이미 보낸 사람은 이름 옆에 “11/9 보냄 ✓”가 붙어요.
  5. 화면 전체 선택은 지금 보이는 사람을 한꺼번에 체크해요. 검색한 다음 누르면 편해요.
  6. 다 골랐으면 다음: 미리보기 (N명)을 눌러요.
엑셀 파일이 필요하면 오른쪽 위 ⋮ → 엑셀로 저장을 누르세요. 보낼 사람만, 또는 전체 연락처를 저장할 수 있어요.
3단계 / 3

확인하고 고치기

  1. 고른 사람마다 실제로 갈 문자가 카드로 보여요. 한 번씩 훑어보세요.
  2. 한 사람만 다르게 보내고 싶으면 카드나 문구 고치기를 눌러요.
    • 문자에서 부를 이름: 연락처에 “김철수 부장”으로 저장돼 있어도 “철수”로 바꿀 수 있어요. 다음에도 기억해요.
    • 이 사람에게 보낼 문구: 이 사람에게만 다른 말을 덧붙일 수 있어요. 공통 문구로 되돌리기로 원래대로 돌아가요.
  3. 빼고 싶은 사람은 빨간 삭제를 눌러요. 이번 목록에서만 빠지고 폰 연락처는 지워지지 않아요. 잘못 눌렀으면 아래에 잠깐 뜨는 되돌리기를 누르세요.
마지막

한꺼번에 보내기

  1. N명에게 모두 보내기를 눌러요.
  2. 처음에는 문자 권한을 물어요. 허용을 눌러요. 막혀 있다는 안내가 나오면 아래 “문자 권한이 막혀 있어요”를 보세요.
  3. “N명에게 보낼까요?”에서 보내기를 눌러요. 한 명씩 약 3초 간격으로 보내요. 50명이면 3분쯤 걸려요.
  4. 보내는 동안에는 앱 화면을 켜 둔 채 기다려 주세요. 중간에 멈추려면 중지를 눌러요.
  5. 다 보내면 “N명에게 전송했습니다”가 떠요. 새로 시작을 누르면 문구 칸이 비워진 1단계로 돌아가요. 다른 사람들에게 다른 문구로 보낼 때 쓰세요.
꼭 먼저 해 보세요. 처음에는 아버지 본인이나 가족 한 명만 골라서 보내 보고, 문자가 제대로 오는지(이름, 줄바꿈, 청첩장 주소) 확인한 다음 여러 명에게 보내세요.
문제가 생기면

자주 막히는 곳

문자 권한이 막혀 있어요 (“제한된 설정”)

안드로이드 13 이상에서는 플레이스토어에서 받지 않은 앱의 문자 권한을 막아 두기도 해요. 앱에서 안내 창이 뜨면 이렇게 풀어 주세요.

  1. 안내 창에서 설정 열기를 눌러요.
  2. 오른쪽 위 ⋮를 누르고 제한된 설정 허용을 눌러요. (이 메뉴가 없으면 건너뛰어요.)
  3. 권한 → SMS로 들어가 허용을 골라요.
  4. 앱으로 돌아와 모두 보내기를 다시 눌러요.
설치가 안 돼요 / “차단됨”이라고 나와요

Play 프로텍트 경고에서 세부정보 더보기를 펼치면 무시하고 설치가 나와요. 그래도 안 되면 설정 → 애플리케이션 → (주소를 연 앱, 예: Chrome·삼성 인터넷) → 출처를 알 수 없는 앱 설치에서 허용을 켜 주세요.

몇 명이 “실패”로 나왔어요

못 보낸 사람은 3단계 목록에 그대로 남아 있어요. 신호가 좋은 곳에서 모두 보내기를 다시 누르면 남은 사람에게만 보내요. 계속 실패하면 번호가 바뀌었을 수 있으니 연락처를 확인해 주세요.

같은 사람에게 두 번 보낼까 걱정돼요

보낸 사람은 2단계 목록에 “날짜 보냄 ✓”가 붙어요. 안 보낸 사람 버튼으로 아직 안 보낸 사람만 볼 수 있어요. 보낼 때도 “이 중 N명은 전에 보낸 적이 있어요”라고 알려 줘요.

문자 요금이 나오나요?

폰에서 직접 보내는 일반 문자라 요금제에 포함된 문자 수가 쓰여요. 문구가 길면 문자 여러 통으로 나뉘어 갈 수 있으니, 요금제가 문자 무제한이 아니라면 미리 확인해 주세요.

보낸 문자는 어디서 볼 수 있나요?

기본 문자 앱에 보낸 문자로 남는 경우가 많지만, 폰 기종에 따라 안 보일 수 있어요. 앱의 엑셀 저장(2단계 ⋮ 메뉴)에는 사람마다 보낸 시각과 마지막으로 보낸 문자가 들어가요.
