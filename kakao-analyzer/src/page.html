우리 카톡,
누가 더 많이 사과했을까?

카카오톡에서 내보낸 대화 파일을 넣으면 어떤 얘기를 많이 했는지, 누가 얼마나 사과했는지, 한 사람이 뭘 하면 상대가 어떻게 반응하는지 정리해 드려요.

대화 파일은 어디에도 올라가지 않아요. 이 화면 안에서만 읽고 분석해요. 인터넷이 끊겨 있어도 돼요.

대화 파일 넣기

.txt, .csv, .zip 파일을 여기로 끌어다 놓거나 골라 주세요.

카톡 대화 내보내는 방법
  1. 안드로이드: 채팅방 오른쪽 위 ≡ → 오른쪽 아래 ⚙ → 대화 내보내기 → 텍스트만 보내기 → 내 파일에 저장하거나 나에게 보내기
  2. 아이폰: 채팅방 오른쪽 위 ≡ → 오른쪽 아래 ⚙ → 대화 내보내기 → 텍스트 메시지만 → 파일에 저장
  3. PC (윈도우): 채팅방 오른쪽 위 ≡ → 대화 내용 → 대화 내보내기 → txt로 저장
  4. 맥: 채팅방에서 ≡ → 대화 내보내기 → csv로 저장

zip으로 받았다면 그대로 넣어도 돼요. 1:1 채팅방이 가장 정확하고, 단체방이면 두 사람을 골라서 볼 수 있어요.

분석은 단어 사전으로 세는 방식이라 말투나 농담에 따라 틀릴 수 있어요. 재미로 봐 주세요.
