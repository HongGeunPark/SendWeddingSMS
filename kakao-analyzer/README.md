# 카톡 연애 분석기

카카오톡에서 내보낸 대화 파일을 넣으면 두 사람의 대화를 분석해 주는 웹 페이지예요.
`index.html` 파일 하나로 돌아가고, 대화는 브라우저 밖으로 나가지 않아요(페이지에 외부 접속을 막는 보안 설정이 들어 있어요).

## 보여 주는 것

- **사과 리포트**: 누가 몇 번 사과했는지, 1,000마디당 몇 번인지, 사과 스타일(미안해형·잘못 인정형·쏘리형 등), 다툼에서 먼저 사과한 사람, 달마다 사과한 횟수
- **반응 패턴**: "A가 사과하면 B는 보통 3분 만에 답했고 62%는 괜찮다고 받아 줬어요"처럼, 한 사람이 뭘 했을 때 상대가 어떻게 반응했는지 (사과, 서운함, 애정 표현, 사진, 크게 웃기, ㅠㅠ, 잘 자, 이모티콘, 질문, 질문에 늦게 답하기, 선톡)
- **대화 주제**: 음식, 데이트, 일, 애정, 갈등, 건강, 돈, 여행, 가족, 결혼·미래 등을 두 사람 비율로 비교
- **대화 유형**: 1시간 넘게 쉬면 새 대화로 나눠서 다툼, 고민·위로, 애정 듬뿍, 약속 잡기, 인사, 폭풍 수다, 일상 보고 등으로 분류
- **다툼 기록**: 다툰 날, 먼저 서운해한 사람, 먼저 사과한 사람, 화해 신호까지 걸린 시간
- **대화 재판**: 다툰 대화마다 판결문과 과실 비율을 내요. "맨날·항상" 같은 단정, 서운하다는 말에 해명부터 하기(말을 안 받아들임), 무응답, 단답·회피, 몰아치기를 잘못으로, 먼저 공감·사과·화해를 정상 참작으로 봐요. 사람마다 대화 스타일(방어형, 단정형, 잠수형 등)과 "그런 뜻 아니야"로 드러난 오해 순간도 증거 대화와 함께 보여 줘요.
- **답장과 리듬**: 답장 속도, 선톡, 질문에 답 안 한 횟수, 달마다 메시지 수, 요일·시간대 히트맵
- **재미 통계**: 사랑해 횟수, ㅋ 개수, 애칭, 많이 쓴 말과 이모지, 가장 긴 메시지, 가장 오래 연락 없던 기간 등

## 쓰는 법

1. `index.html`을 내려받아 브라우저(크롬, 사파리, 엣지)로 열어요. 폰에서도 열려요.
2. 카톡 대화를 내보내요.
   - 안드로이드: 채팅방 ≡ → ⚙ → 대화 내보내기 → 텍스트만 보내기
   - 아이폰: 채팅방 ≡ → ⚙ → 대화 내보내기 → 텍스트 메시지만
   - PC: 채팅방 ≡ → 대화 내용 → 대화 내보내기
   - 맥: 채팅방 ≡ → 대화 내보내기 (csv)
3. 받은 `.txt` / `.csv` / `.zip` 파일을 페이지에 끌어다 놓거나 "파일 고르기"로 골라요.

처음 열면 가짜 커플 "민준·서연"의 예시 대화가 보여요.

## 알아 둘 점

분석은 단어 사전으로 세는 방식이에요. "미안"이 들어가면 사과로, "서운", "짜증"이 들어가면 서운함으로 봐요(같은 메시지에 ㅋㅋ가 있으면 장난으로 보고 빼요). 그래서 말투나 농담에 따라 틀릴 수 있어요.
사전은 `src/core.js`의 `R`, `TOPICS`, `APOLOGY_TYPES`에 있어요.

## 고치는 법

`src/` 아래 파일을 고친 뒤 하나짜리 `index.html`을 다시 만들어요.

```
node build.js            # index.html 만들기
node test/run-tests.js   # 테스트 (안드로이드·옛 안드로이드·아이폰·PC·맥 형식, zip, 분석)
```

| 파일 | 내용 |
|---|---|
| `src/core.js` | 파일 읽기(zip, 인코딩), 형식별 파싱, 분석, 예시 대화 |
| `src/ui.js` | 화면 그리기 |
| `src/style.css` | 스타일 (라이트·다크 모드) |
| `src/page.html` | 페이지 뼈대 |
