# 청첩장 연락처 (SendWeddingSMS)

모바일 청첩장을 보내기 위해 안드로이드 폰의 연락처를 엑셀(.xlsx)로 정리하는 앱이에요.

## 쓰는 순서

앱은 한 흐름으로 움직여요. 한 번 다 보내면 처음으로 돌아가 빈 칸으로 새로 시작해요.

1. **문구 쓰기**: 청첩장 주소와 이번에 보낼 문구를 써요. `{이름}`은 받는 사람 이름, `{이름아}`는 "철수야/길동아"로 바뀌어요. 청첩장 주소는 한 번 넣으면 기억하고, 문구 아래에 한 줄 띄우고 붙어요.
2. **받는 사람 고르기**: 폰 연락처를 불러와서 이번 문구를 보낼 사람을 체크해요. 이름, 초성(`ㅎㄱㄷ`), 번호로 검색하고 "고른 사람 / 안 보낸 사람"만 볼 수 있어요. 전에 보낸 사람은 "보냄 ✓"이 붙어요. 오른쪽 위에서 엑셀로 저장할 수 있어요.
3. **확인하고 보내기**: 사람마다 실제로 갈 문자가 보여요. 카드를 누르면 그 사람 문구나 부를 이름만 고칠 수 있고, "삭제"를 누르면 이번 목록에서 빠져요(폰 연락처는 그대로예요). "모두 보내기"를 누르면 약 3초 간격으로 한 명씩 바로 전송돼요. 다 보내면 "전송했습니다"가 뜨고 처음으로 돌아가요.

못 보낸 사람이 있으면 목록에 남아 있어서 다시 "모두 보내기"를 누르면 그 사람들에게만 가요. 앱이 중간에 꺼져도 쓰던 문구와 고른 사람은 남아 있어요. 인터넷 권한이 없어서 연락처가 폰 밖으로 나가지 않아요.

## 설치하기

1. 이 저장소의 **Releases → 최신 APK**에서 `SendWeddingSMS.apk`를 폰으로 받아요.
   (PC에서 받았다면 카톡 "나와의 채팅"이나 USB로 폰에 옮겨요.)
2. 받은 파일을 누르면 "출처를 알 수 없는 앱" 설치 허용을 물어봐요. 파일을 연 앱(내 파일, 크롬 등)에 대해 **허용**을 켜고 돌아와서 **설치**를 눌러요.
3. "Play 프로텍트" 경고가 뜨면 **세부정보 → 무시하고 설치**를 눌러요. 개인용으로 만든 앱이라 뜨는 경고예요.
4. 앱을 처음 열면 연락처 권한을 물어봐요. **허용**을 눌러요.

문자를 처음 보낼 때 문자 권한을 물어봐요. 권한 창이 안 뜨거나 "제한된 설정"이라고 나오면: 설정 → 애플리케이션 → 청첩장 연락처 → 오른쪽 위 ⋮ → **제한된 설정 허용** → 권한 → SMS → 허용.

새 버전은 지우지 않고 그대로 덮어 설치하면 돼요. 고른 내용도 그대로 남아요.

## 빌드

GitHub Actions(`.github/workflows/build-apk.yml`)가 푸시할 때마다 테스트와 APK 빌드를 해요.
직접 빌드하려면 Android SDK가 있는 환경에서 `./gradlew assembleDebug`를 실행하세요.
