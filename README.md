# 청첩장 연락처 (SendWeddingSMS)

모바일 청첩장을 보내기 위해 안드로이드 폰의 연락처를 엑셀(.xlsx)로 정리하는 앱이에요.

## 할 수 있는 것

- 폰 연락처를 바로 읽어서 한 사람당 한 줄로 보여 줘요. 번호는 `010-1234-5678` 형식으로 맞추고, 같은 번호로 두 번 저장된 연락처는 하나로 합쳐요.
- 줄을 누르면 "보낼 사람"으로 체크돼요. 오른쪽 버튼으로 관계(가족·친척, 직장, 친구 등)를 고를 수 있어요.
- 이름, 초성(`ㅎㄱㄷ`), 번호 일부로 검색할 수 있고, "보낼 사람 / 안 고른 사람"만 따로 볼 수 있어요.
- 체크한 내용은 폰에 저장돼서 앱을 껐다 켜도 이어서 고를 수 있어요.
- "엑셀로 저장"을 누르면 보낼 사람만, 또는 전체(보낼지 O/X 표시)를 엑셀로 저장해요. 저장 후 "보내기"로 카톡이나 메일로 바로 보낼 수 있어요.
- 인터넷 권한이 없어서 연락처가 폰 밖으로 나가지 않아요.

엑셀 열: 순번, 이름, 전화번호, 기타 번호, 관계, 보낼지, 메모

## 설치하기

1. 이 저장소의 **Releases → 최신 APK**에서 `SendWeddingSMS.apk`를 폰으로 받아요.
   (PC에서 받았다면 카톡 "나와의 채팅"이나 USB로 폰에 옮겨요.)
2. 받은 파일을 누르면 "출처를 알 수 없는 앱" 설치 허용을 물어봐요. 파일을 연 앱(내 파일, 크롬 등)에 대해 **허용**을 켜고 돌아와서 **설치**를 눌러요.
3. "Play 프로텍트" 경고가 뜨면 **세부정보 → 무시하고 설치**를 눌러요. 개인용으로 만든 앱이라 뜨는 경고예요.
4. 앱을 처음 열면 연락처 권한을 물어봐요. **허용**을 눌러요.

새 버전은 지우지 않고 그대로 덮어 설치하면 돼요. 고른 내용도 그대로 남아요.

## 빌드

GitHub Actions(`.github/workflows/build-apk.yml`)가 푸시할 때마다 테스트와 APK 빌드를 해요.
직접 빌드하려면 Android SDK가 있는 환경에서 `./gradlew assembleDebug`를 실행하세요.
